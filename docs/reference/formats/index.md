# File formats

petro-image uses JSON, GeoJSON, and CSV files for libraries, annotations, counts, recipes, and analytical results. This section records exact format contracts; workflow instructions remain in the relevant user-guide or tool page.

## Currently documented contracts

- [Library JSON](library-json.md)
- [Annotation GeoJSON](annotations-geojson.md)

## Tool-specific files

The following files are currently described with the tool that creates or consumes them:

- Grid and point-count GeoJSON and CSV: [Grid & Count](../../tools/grid-and-point-count.md)
- Measurement CSV and plot exports: [Measure](../../tools/measure.md)
- Porosity recipes, summaries, and rasters: [Estimate Porosity](../../tools/estimate-porosity.md)
- Segmentation outputs: [Segment](../../tools/segment.md)
- Transform rasters and tables: [Transform](../../tools/transform.md)
