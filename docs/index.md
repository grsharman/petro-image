# petro-image documentation

Welcome to the petro-image documentation. Choose a starting point based on what you want to accomplish.

## New users

- [Your first session](getting-started/first-session.md): select a specimen, navigate a high-resolution image, and compare image layers.
- [Viewing and comparing images](user-guide/viewing-and-comparing.md): understand layers, divided views, opacity, and rotation.
- [Tools and analytical methods](tools/index.md): choose a tool and understand its purpose, method, outputs, assumptions, and limitations.

## Use your own data

- [Using your own images](importing/index.md): understand the route from source microscopy images to a petro-image library.
- [Library JSON and related formats](reference/formats/index.md): exact structures, attributes, and coordinate conventions.

## Tools and methods

- [Tools](tools/index.md): Measure, Annotate, Grid & Count, Snapshot, Segment, Transform, Estimate Porosity, and Classify, with method-specific pages for specialized calculations.

## Reference

- [Reference](reference/index.md): shortcuts, library files, GeoJSON, coordinates, units, and the embedded viewer API.

## How these docs are organized

The documentation has several complementary kinds of pages:

- **Getting started** pages provide a gentle introduction.
- **User guides** explain complete application workflows.
- **Tools and methods** pages explain how petro-image creates, measures, or analyzes data and how its outputs should be interpreted.
- **Reference** pages give exact file-format, interface, and API details.
