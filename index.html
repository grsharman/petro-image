          Grid & Point Count Help
          
        

        

          
Create a Grid

          
Use the Grid section to set the area of interest, point spacing, and the number of points. Crosshair appearance can also be adjusted. Click Apply to create the grid. Applying or clearing a grid replaces existing grid and point-count data, so export your work before clearing the grid.

          
Gridding Algorithm

          
The gridding algorithm places points at the specified spacing value. If the area of interest is not large enough to accomodate the number of points, an infill pattern is used to place points between existing locations. It is good practice to create more points than you think you need, in case you have to count more than you anticipated (e.g., create 600 points if you plan on a n=400 point count).

          
Enter Point Counts

          
Use the Count section to navigate between crosshairs. Enter an identifier or notes and press Enter to record the value. Press Space to advance to the next point and Shift+Space to return to the previous point. Hint: Using a code (e.g., A for quartz) can make point-counting faster. Use notes to provide metadata for each count (e.g., note uncertain idenfications).

          
Review Results

          
Select chooses which identifiers appear in the summary. Summarize displays counts and percentages. Filter limits the visible crosshairs to selected identifiers.

          
Import and Export

          
JSON preserves point-count data and grid appearance. CSV supports exchanging point locations and count values, but does not preserve all appearance settings.

          
Performance

          
Very dense grids can slow display and interaction. Reduce the point count or enlarge the grid spacing if performance becomes sluggish.

          Snapshot Help
          
        

        

          
What It Does

          
Snapshot captures a selected image area as a JPG, with options for including visible annotations, labels, a scalebar, the currently displayed porosity overlay, and an applied image filter (if there is one).

          
Select an Area

          
Click Draw Area and click+drag over the image, or use the current screen extent. Drag the box or its handles to adjust the snapshot area.

          
Contents and Resolution

          
Choose the tile set and whether to include annotations and labels. Full, half, and quarter resolution use source-image pixels. Current viewer resolution captures the detail currently displayed. The dimensions table previews the chosen output size.

          
Scalebar and Filter

          
The option to include a scalebar in the image is enabled when image scale is available. Export applied filter uses the active Transform Imagery preview instead of the raw tile set.

          
Save or Copy

          
Save to JPG opens the file-save workflow. Copy to Clipboard places the rendered image directly on the system clipboard and keeps the selected area available.

          
Output Limits

          
Snapshots are limited to 16,000 pixels per side and 100 megapixels total. Choose a lower resolution or a smaller area when the limit is exceeded.

          Transform Imagery Help
          
        

        

          
What It Does

          
Transform Imagery allows filters and calculations to be made on tile sets. Results can be previewed on the fly, or saved to their own tile set (enabling faster loading for calculations).

          
Simple Filter

          
Use Simple Filter for common visual filters such as edge detection, local contrast, unsharp masking, relief shading, and channel mapping. These are intended for quick visual exploration.

          
Image Calculator

          
Use Image Calculator to build expressions from tile-set channels. Calculations can be performed on any tile set (labeled A, B, C, etc.) for R, G, B, luminance, saturation, and hue. Supported functions include abs, normdiff, range, max, min, and mean.

          
Tile-Set Stack Functions

          
range, max, min, and mean summarize all images within the selected source tile set at each pixel. A single-image tile set has a range of 0.

          
Polarization Analysis

          
Assign PPL, XPL, and CPL roles to angle-aware tile sets. Polarization products use harmonic fits when at least three valid angles are available; six well-spaced images are preferred. Input channel selects the source-image intensity fitted at each angle; Red, Green, Blue, and Luminance are supported. RGB output is available for predicted PPL maximum or minimum transmission and predicted XPL maximum or minimum. It derives one orientation from luminance, then evaluates the fitted red, green, and blue channels at that shared orientation. The XPL predicted minimum corresponds to the fitted extinction orientation. Normalized RMSE maps show residual error relative to fitted brightness and modulation. Azimuth uncertainty is an approximate one-standard-error value based on residual variance and acquisition geometry; it requires more than three images. PPL and XPL azimuth reliability are separate binary maps that reproduce the modality-specific Fits = Reliable criteria. PPL–XPL azimuth difference reports the nearest symmetry-equivalent separation from 0° to 45° and is not a crystallographic misorientation. Direct stack statistics such as mean and range remain available in Image Calculator. XPL fitting assumes crossed polarizer and analyzer rotation.

          
Anisotropy Classification

          
Anisotropy class combines observed PPL/XPL brightness with luminance-based harmonic fits. A single very dark PPL image can support an opaque-like result. Isotropic-like / continuously extinct means PPL is transmissive while observed XPL remains below the extinction ceiling at every measured angle; XPL fit quality is not used when the signal is continuously dark. This remains an optical-behavior description rather than a mineral identification. Pleochroism requires both normalized PPL modulation and a minimum absolute, noise-relative amplitude. Missing evidence is never treated as a negative response, and unavailable legend classes show a dash rather than 0%. Classification confidence reflects threshold separation, angular sampling, fit quality when a fit is identifiable, and input completeness. Presets are general-purpose starting points rather than petrographically calibrated standards.

          
Resolution and Raster Export

          
The selected analysis resolution is used for generated tile sets and raster exports. NumPy and TIFF preserve scalar calculated values; for RGB polarization display they retain the corresponding luminance calculation. PNG and JPEG export the current display mapping. Maximum available uses source-image resolution and may require substantial memory.

          
Display and Histogram

          
The preview is mapped to a display image. Calculator Auto min/max estimates one range from a whole-image overview and locks that range across all preview tiles and zoom levels. It does not rescale individual tiles or change with the viewport. Calculator histograms use the selected Output range as their fixed analytical axis; the bars continue to update for the visible pixels. Scalar polarization histograms retain their analytical units, while anisotropy class shows a categorical distribution and legend. Grayscale and false-color analytical histograms include a colorbar aligned with the numerical axis; RGB and classification displays omit it. For Polarization Analysis, switch to Fit at cursor to compare the measured per-angle intensities with the harmonic fit at a point. The panel reports fitted minimum, maximum, modulation, azimuth, RMSE, and normalized RMSE. Double-click a loaded preview point to pin it directly; the marker remains in the viewer while you pan, zoom, or use the controls. The Unpin button returns the plot to live cursor updates. Histogram, Rose, and Preview views of PPL maximum-transmission and XPL extinction azimuths share an All or Reliable fit filter and report the included fraction and sample count. All is the default. Reliable retains fits that pass the current fit-error, modulation, and signal thresholds and displays excluded preview pixels in neutral grey without changing their analytical values. Rose expands the native 180° PPL or 90° XPL ambiguity symmetrically around the full circle.

          
Export Notes

          
Preview changes are temporary. Use Generate Tile Set to make a persistent transformed tile set. Higher output resolutions preserve more detail but take longer to render. Exported images may be deleted using the Edit Library action.

        

      

      

        

          Classify Polygons Help
          
        

        

          
What It Does

          
Classify Polygons predicts labels for unlabeled polygons by training from labeled polygon annotations. Predictions are kept committed when Apply Groups is clicked.

          
Basic Workflow

          
Choose which polygons to use, the source of training labels, the tile set(s) to use for training, and the image resolution. After clicking Extract Features, select a model and click Train + Predict. Review predictions and add additional training labels before clicking Train + Predict again. Highlighting uncertain polygons can help with adding labels where they are needed the most. Iterate by adding labels and making predictions until you are happy with the results. Then click "Apply Groups" to extend predictions to the annotations.

          
Image Features

          
For each selected tile set, the tool samples pixels inside each polygon and summarizes color and brightness. Parameters extracted include RGB means and standard deviations; luminance mean, spread, and range; saturation mean and spread; and a simple internal luminance-edge estimate.

          
Shape Features

          
Shape measurements are optional. When enabled, area, perimeter, circularity, solidity, width, height, long axis, short axis, and aspect ratio are included with the image features.

          
Models

          
Random Forest is the default model. K-Nearest Neighbors (kNN) is also available. The current Random Forest is a lightweight in-app implementation intended for interactive exploration rather than final research-grade model validation.

          
Confidence and Groups

          
Confidence is useful for triage, especially with Highlight Low. Apply Groups assigns predicted labels to annotation groups. Leave Include low confidence unchecked to skip predictions below the minimum confidence threshold.

          
Beta Notes

          
Feature choices, tile-set roles, model tuning, and confidence calibration are still experimental. Export the table when you want to inspect or compare results outside the app.

          Estimate Porosity Help
          
        

        

          
What It Does

          
Estimate Porosity measures the area fraction of pore-colored pixels inside a polygon AOI. More than one porosity type can be estimated (e.g., macroporosity vs microporosity). Results are shown by porosity type and as a combined total.

          
Basic Workflow

          
Draw an AOI, choose one or more tile sets, pick representative pore colors, then click Estimate View or Estimate AOI. Estimate View is a temporary check of the visible part of the AOI; Estimate AOI commits results for the whole AOI.

          
Porosity Types

          
Use multiple porosity types when different pore colors or textures should be tracked separately. Each type has its own color samples, tolerance, overlay color, opacity, and result. Select polygon annotations that intersect the AOI and use Add selected polygons to force their area to porosity. This can be useful when a pore contains a bubble.

          
Color Picking and Tolerance

          
Pick several representative pore pixels for each pore type. With multiple tile sets, each pick is shown as a linked swatch column. Click any swatch to select its whole column, then press Delete or Backspace to remove that linked pick. Higher tolerance includes a broader range of similar colors; lower tolerance keeps the match stricter. Adjusting tolerance updates the estimate after a result exists.

          
Resolution

          
Fast preview is quicker and lower detail. Balanced is the default. High detail and Maximum available preserve more image detail but take longer to render and analyze. Local-thickness calculations on very large analysis rasters show a memory/time warning before continuing.

          
Calculated Properties

          
Calculate properties computes local thickness, distance to boundary, and connected-component properties. Each pore pixel is assigned the diameter of the largest circle that overlaps it and remains inside that porosity type. The Parameter menu also displays component area, equivalent diameter, mean/max thickness, circularity, aspect ratio, orientation, and ID.

          
Histogram Controls

          
Use the histogram Plot menu to compare local thickness, distance to boundary, component properties, or chord lengths. Weight defaults to pore area. The AOI edge filter can exclude complete pores that touch the analysis edge; it is unavailable for chord lengths because chord values are not linked to component IDs.

          
Recipes and Results

          
Recipe JSON saves the AOI, tile-set selections, color picks, settings, and embedded manual-polygon geometry. Import validates the source sample and automatically estimates the full AOI. Results & export also provides summary CSV/JSON files.

          
Raster Export and Further Analysis

          
Export AOI-cropped binary porosity masks or calculated-property rasters as NumPy arrays, TIFF, PNG, or JPEG, each with source-image-coordinate metadata. Numeric NumPy and TIFF outputs are suitable for downstream Python workflows and more sophisticated porous-media analysis, including PoreSpy (Gostick et al., 2019). Composite calculated-property exports combine all compatible porosity types into one raster.

          
AOI Editing

          
Drag to draw a rectangular AOI. After drawing, drag vertices to refine it. Double-click an edge or Option-click an edge to add a vertex, and use Delete or Backspace to remove the selected vertex. The eye button hides or shows the AOI overlay without clearing results.

          
Beta Notes

          
This tool estimates porosity from sampled color similarity. Lighting changes, stains, shadows, and mixed pixels can affect results, so review the overlay and tune samples/tolerance before treating measurements as final.

          Segment Help
          
        

        

          
What It Does

          
Supervised Segmentation uses SAM 2.1 with box and point prompts. segmenteverygrain uses a U-Net model to propose grains and can refine their outlines with SAM 2.1.

          
Create the Python Environment

          
    
            
  1. Install Miniforge (recommended) or another conda/mamba distribution.
    2. 
            
  2. Clone the project with git clone --depth 1 https://github.com/zsylvester/segmenteverygrain.git.
    3. 
            
  3. In Terminal or Anaconda Prompt, run conda env create -f segmenteverygrain/environment_macos.yml on macOS, or conda env create -f segmenteverygrain/environment.yml on Windows/Linux.
    4. 
            
  4. Activate it with conda activate segmenteverygrain.
    5. 
          

          
The official environment file installs Python 3.10 and the required segmenteverygrain, TensorFlow, PyTorch, torchvision, SAM 2, OpenCV, and scikit-image dependencies.

          
Find the Python File

          
Run conda run -n segmenteverygrain python -c "import sys; print(sys.executable)". Copy the printed path. In SAM 2.1 Setup, click Choose Python and select that exact file. It normally ends in /bin/python on macOS/Linux or python.exe on Windows.

          
Download the Models

          
Download a SAM 2.1 .pt checkpoint from github.com/facebookresearch/sam2, choose the matching model size, and select it under SAM 2.1 Setup.

          
Clone or download github.com/zsylvester/segmenteverygrain, then select a trained .keras file from its models folder (for example, seg_model_smooth_labels.keras) under segmenteverygrain Setup. Installing only the Python package does not necessarily download this model file.

          
Test the Setup

          
Click Test SAM, then Test segmenteverygrain. The readiness indicators should turn green before running either workflow.

          
Using the Tools

          
For supervised segmentation, draw a box and optionally add positive or negative points, then add the result as an annotation. For segmenteverygrain, draw an AOI, choose a processing resolution, review the estimated pixel load, and run the model.

            Controls Help
            
          

          

            
Groups and samples

            
Use the group and sample drop-down menus to select a sample from the loaded library. Groups contain related samples; choosing a sample updates the available tile sets, scale, annotation files, and relevant controls for that sample.

            
Tile sets

            
The tile set checkboxes turn image layers on and off. Ctrl+1-9 or Alt+1-9 toggles a tile set, Ctrl+Shift+1-9 or Alt+Shift+1-9 shows only that tile set, and Alt+0 hides all tile sets.

            
Rotation

            
Image rotation rotates the displayed view. Stage rotation is available when the sample has one or more rotation-aware tile sets. The displayed image mimics the effects of stage rotation (e.g., changing interference colors under cross-polarization). Lock stage keeps image rotation synchronized with stage rotation.

            
Rotation shortcuts

            
For multiple-image tile sets that are not tied to stage rotation, Shift+Left or Shift+< steps to the previous image and Shift+Right or Shift+> steps to the next image across all eligible tile sets.

                Annotate Help
                
              

              

                
Drawing annotations

                
Choose a drawing tool by clicking on it in the toolbar or using the keyboard shortcut, then click in the image to create points, lines, polygons, rectangles, ellipses, or circles. For line and polygon tools, complete the shape with a double-click.

                
Annotation drawing shortcuts

                
Use the following shortcuts to draw annotations:

                
    
                  
  • Point: Q+click in the image to create a point.
    • 
                  
  • Line: Hold Z+click to create line vertices, then double-click to complete the shape.
    • 
                  
  • Polygon: Hold X+click to create polygon vertices, then double-click to complete the shape.
    • 
                  
  • Rectangle: Hold Alt/Option while dragging to create a rectangle.
    • 
                  
  • Ellipse: Hold C+click to create an ellipse. The first click sets the center, the second click sets the longaxis, and final click sets the short axis.
    • 
                  
  • Circle: Hold V+click to create a circle. The first click sets the center, and the second click sets the radius. A set radius can be defined under "Circle Controls" button if image scale is defined. In this case, the circle is created upon V+click.
    • 
                  
  • Label: Press l to open the Label dialog when an annotation is selected.
    • 
                

                
Selecting annotations

                
Click an annotation in the image or table to select it. Holding shift while clicking and dragging will select multiple annotations, while deselecting any that are already selected. Ctrl/Command-click annotations or rows in the table to add or remove individual annotations from the selection. Shift-click selects a range in the current filtered/sorted list. Ctrl/Command+A selects all shown, unlocked rows when the annotation table is active.

                
List sorting and filtering

                
The grey annotation-list header allows filtering and sorting. Click the group, number, type, geometry warning, label, visibility, or lock header to sort, filter, clear filters, or select all shown annotations. Active filters and sorts are highlighted in yellow.

                
Groups, visibility, and locks

                
The group row assigns selected annotations to groups, changes group color, toggles group visibility, and locks or unlocks a group. Row eye and lock buttons affect individual annotations. Locked annotations cannot be selected for editing until unlocked.

                
Editing geometry

                
Double click an annotation to enable editing. Individual vertices can be moved. Double click the shape margin to add a vertex. Ctrl/Command-click on a vertext to delete it. Dragging the white circle moves the annotation, whereas the yellow circle can be used to rotate the annotation. Use Move Annotation Label to reposition the selected label. 

                
Text and appearance

                
The Label and Notes fields allow information to be stored with each annotation. Annotation Appearance controls label style, line style, fill style, and opacity. Apply Current updates the selected annotation, while Apply All updates compatible annotations together.

                
Import and export

                
GeoJSON import supports points, multipoints, lines, multilines, polygons, and multipolygons. Imported annotations can be assigned to a chosen group or keep groups from the file. Export writes visible annotation geometry and annotation properties to GeoJSON.

                
Useful shortcuts

                
Undo and redo use the standard system shortcuts. Escape closes open annotation popovers and cancels active drawing/editing states where applicable. Delete removes selected unlocked annotations. Ctrl-click or Command-click toggles row selection; Shift-click selects a row range; Ctrl+A or Command+A selects all shown rows when the annotation list is active.

                Measure Help
                
              

              

                
Scale and units

                
Measurements require a known image scale. The scale audit chip at the bottom of the window shows the current calibration and displays units used in the table, plots, and CSV exports.

                
Line measurements

                
Length is reserved for polylines and is calculated as the sum of segment lengths.

                
Polygon measurements

                
Area and perimeter use the polygon exterior and any interior rings. Invalid self-intersecting polygons are flagged because area and equivalent circular diameter (ECD) may be unreliable. Area and perimeter for MultiPolygons are calculated as the sum of the areas and perimeters of the constituent polygons.

                
Axes and orientation

                
Long axis and short axis describe the oriented bounding axes of the geometry (i.e., the minimum enclosing rectangle). Long axis azimuth is reported in degrees.

                
Feret diameters

                
Max Feret is the greatest caliper distance across the polygon. Min Feret is the smallest caliper width across the convex hull.

                
Shape metrics

                
ECD (equivalent circular diameter) is the diameter of a circle with the same area. Short/Long is the axis ratio. Solidity compares polygon area to convex hull area. Circularity summarizes compactness from area and perimeter.

                
Filtering and plots

                
Table header filters affect the table, CSV export, and Measure plots. Histogram, scatterplot, rose diagram, and particle-size analysis use the currently filtered measurement set.
