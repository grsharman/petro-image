Classify Polygons Help

What It Does

Classify Polygons predicts labels for unlabeled polygons by training from labeled polygon annotations. Predictions are kept committed when Apply Groups is clicked.

Basic Workflow

Choose which polygons to use, the source of training labels, the tile set(s) to use for training, and the image resolution. After clicking Extract Features, select a model and click Train + Predict. Review predictions and add additional training labels before clicking Train + Predict again. Highlighting uncertain polygons can help with adding labels where they are needed the most. Iterate by adding labels and making predictions until you are happy with the results. Then click "Apply Groups" to extend predictions to the annotations.

Image Features

For each selected tile set, the tool samples pixels inside each polygon and summarizes color and brightness. Parameters extracted include RGB means and standard deviations; luminance mean, spread, and range; saturation mean and spread; and a simple internal luminance-edge estimate.

Shape Features

Shape measurements are optional. When enabled, area, perimeter, circularity, solidity, width, height, long axis, short axis, and aspect ratio are included with the image features.

Models

Random Forest is the default model. K-Nearest Neighbors (kNN) is also available. The current Random Forest is a lightweight in-app implementation intended for interactive exploration rather than final research-grade model validation.

Confidence and Groups

Confidence is useful for triage, especially with Highlight Low. Apply Groups assigns predicted labels to annotation groups. Leave Include low confidence unchecked to skip predictions below the minimum confidence threshold.

Beta Notes

Feature choices, tile-set roles, model tuning, and confidence calibration are still experimental. Export the table when you want to inspect or compare results outside the app.

Controls Help

Groups and samples

Use the group and sample drop-down menus to select a sample from the loaded library. Groups contain related samples; choosing a sample updates the available tile sets, scale, annotation files, and relevant controls for that sample.

Tile sets

The tile set checkboxes turn image layers on and off. Ctrl+1-9 or Alt+1-9 toggles a tile set, Ctrl+Shift+1-9 or Alt+Shift+1-9 shows only that tile set, and Alt+0 hides all tile sets.

Rotation

Image rotation rotates the displayed view. Stage rotation is available when the sample has one or more rotation-aware tile sets. The displayed image mimics the effects of stage rotation (e.g., changing interference colors under cross-polarization). Lock stage keeps image rotation synchronized with stage rotation.

Rotation shortcuts

For multiple-image tile sets that are not tied to stage rotation, Shift+Left or Shift+< steps to the previous image and Shift+Right or Shift+> steps to the next image across all eligible tile sets.

Annotate Help

Drawing annotations

Choose a drawing tool by clicking on it in the toolbar or using the keyboard shortcut, then click in the image to create points, lines, polygons, rectangles, ellipses, or circles. For line and polygon tools, complete the shape with a double-click.

Annotation drawing shortcuts

Use the following shortcuts to draw annotations:

  • Point: Q+click in the image to create a point.
  • Line: Hold Z+click to create line vertices, then double-click to complete the shape.
  • Polygon: Hold X+click to create polygon vertices, then double-click to complete the shape.
  • Rectangle: Hold Alt/Option while dragging to create a rectangle.
  • Ellipse: Hold C+click to create an ellipse. The first click sets the center, the second click sets the longaxis, and final click sets the short axis.
  • Circle: Hold V+click to create a circle. The first click sets the center, and the second click sets the radius. A set radius can be defined under "Circle Controls" button if image scale is defined. In this case, the circle is created upon V+click.
  • Label: Press l to open the Label dialog when an annotation is selected.

Selecting annotations

Click an annotation in the image or table to select it. Holding shift while clicking and dragging will select multiple annotations, while deselecting any that are already selected. Ctrl/Command-click annotations or rows in the table to add or remove individual annotations from the selection. Shift-click selects a range in the current filtered/sorted list. Ctrl/Command+A selects all shown, unlocked rows when the annotation table is active.

List sorting and filtering

The grey annotation-list header allows filtering and sorting. Click the group, number, type, geometry warning, label, visibility, or lock header to sort, filter, clear filters, or select all shown annotations. Active filters and sorts are highlighted in yellow.

Groups, visibility, and locks

The group row assigns selected annotations to groups, changes group color, toggles group visibility, and locks or unlocks a group. Row eye and lock buttons affect individual annotations. Locked annotations cannot be selected for editing until unlocked.

Editing geometry

Double click an annotation to enable editing. Individual vertices can be moved. Double click the shape margin to add a vertex. Ctrl/Command-click on a vertext to delete it. Dragging the white circle moves the annotation, whereas the yellow circle can be used to rotate the annotation. Use Move Annotation Label to reposition the selected label.

Text and appearance

The Label and Notes fields allow information to be stored with each annotation. Annotation Appearance controls label style, line style, fill style, and opacity. Apply Current updates the selected annotation, while Apply All updates compatible annotations together.

Import and export

GeoJSON import supports points, multipoints, lines, multilines, polygons, and multipolygons. Imported annotations can be assigned to a chosen group or keep groups from the file. Export writes visible annotation geometry and annotation properties to GeoJSON.

Useful shortcuts

Undo and redo use the standard system shortcuts. Escape closes open annotation popovers and cancels active drawing/editing states where applicable. Delete removes selected unlocked annotations. Ctrl-click or Command-click toggles row selection; Shift-click selects a row range; Ctrl+A or Command+A selects all shown rows when the annotation list is active.

Measure Help

Scale and units

Measurements require a known image scale. The scale audit chip at the bottom of the window shows the current calibration and displays units used in the table, plots, and CSV exports.

Line measurements

Length is reserved for polylines and is calculated as the sum of segment lengths.

Polygon measurements

Area and perimeter use the polygon exterior and any interior rings. Invalid self-intersecting polygons are flagged because area and equivalent circular diameter (ECD) may be unreliable. Area and perimeter for MultiPolygons are calculated as the sum of the areas and perimeters of the constituent polygons.

Axes and orientation

Long axis and short axis describe the oriented bounding axes of the geometry (i.e., the minimum enclosing rectangle). Long axis azimuth is reported in degrees.

Feret diameters

Max Feret is the greatest caliper distance across the polygon. Min Feret is the smallest caliper width across the convex hull.

Shape metrics

ECD (equivalent circular diameter) is the diameter of a circle with the same area. Short/Long is the axis ratio. Solidity compares polygon area to convex hull area. Circularity summarizes compactness from area and perimeter.

Filtering and plots

Table header filters affect the table, CSV export, and Measure plots. Histogram, scatterplot, rose diagram, and particle-size analysis use the currently filtered measurement set.
